# Руководство по управлению FAQ

## Обзор

Система FAQ позволяет администраторам управлять часто задаваемыми вопросами через админ-панель. Вопросы автоматически группируются по категориям и отображаются на публичной странице сайта.

## Доступ к управлению FAQ

### Через админ-панель

1. Войдите в систему с правами **Manager** или выше
2. Перейдите в админ-панель: `/staff-admin/`
3. Найдите раздел **CONTENT** → **FAQ**

### Права доступа

- **Просмотр**: Manager и выше
- **Добавление/Редактирование**: Manager и выше
- **Удаление**: Admin и выше

## Создание нового FAQ

### Шаг 1: Добавление вопроса

1. В админ-панели нажмите **"Добавить FAQ"**
2. Заполните поля:
   - **Вопрос** — краткий и понятный вопрос (до 500 символов)
   - **Ответ** — подробный ответ с форматированием
   - **Категория** — выберите подходящую категорию
   - **Активен** — отметьте для публикации на сайте
   - **Порядок сортировки** — число для управления порядком отображения

### Шаг 2: Выбор категории

Доступные категории:
- **Бронирование** — вопросы о процессе бронирования
- **Заезд и выезд** — время заезда/выезда, документы
- **Услуги** — удобства, парковка, питание
- **Оплата** — способы оплаты, возврат средств
- **Общее** — прочие вопросы

### Шаг 3: Форматирование ответа

Ответы поддерживают:
- Переносы строк (автоматически преобразуются в параграфы)
- Списки (используйте символы • или -)
- Выделение важной информации

**Пример хорошего ответа:**

```
Вы можете забронировать номер несколькими способами:

1. Онлайн на нашем сайте
2. По телефону
3. Лично на стойке регистрации

После бронирования вы получите подтверждение на email.
```

## Управление существующими FAQ

### Редактирование

1. В списке FAQ нажмите на вопрос
2. Внесите изменения
3. Нажмите **"Сохранить"**

### Изменение порядка отображения

1. В списке FAQ найдите колонку **"Порядок сортировки"**
2. Измените число (меньшее число = выше в списке)
3. FAQ с одинаковым порядком сортируются по алфавиту

### Деактивация вопроса

Чтобы временно скрыть вопрос без удаления:
1. Снимите галочку **"Активен"**
2. Сохраните изменения

Или используйте массовое действие:
1. Выберите несколько FAQ (чекбоксы слева)
2. В выпадающем списке выберите **"Деактивировать выбранные FAQ"**
3. Нажмите **"Выполнить"**

### Удаление

**Внимание:** Удаление необратимо!

1. Выберите FAQ для удаления
2. В выпадающем списке выберите **"Удалить выбранные FAQ"**
3. Подтвердите удаление

## Массовые операции

Доступные действия для выбранных FAQ:
- **Активировать** — опубликовать на сайте
- **Деактивировать** — скрыть с сайта
- **Удалить** — удалить безвозвратно

## Создание примеров FAQ

```bash
python manage.py create_sample_faq
```

Эта команда создаст 15 примеров FAQ по всем категориям.

## Отображение на сайте

### Публичная страница

FAQ доступны по адресу: `/faq/`

Ссылка автоматически добавлена в:
- Главное меню навигации
- Футер сайта

### Группировка

Вопросы автоматически группируются по категориям с иконками:
- 📅 Бронирование
- 🚪 Заезд и выезд
- ⭐ Услуги
- 💳 Оплата
- ℹ️ Общее

### Аккордеон

Каждый вопрос отображается в виде аккордеона:
- Клик по вопросу раскрывает ответ
- Первый вопрос в каждой категории раскрыт по умолчанию
- Плавная анимация раскрытия/скрытия

## Рекомендации по контенту

### Хорошие практики

✅ **Делайте:**
- Используйте простой и понятный язык
- Структурируйте ответы списками
- Добавляйте конкретные цифры и сроки
- Предоставляйте альтернативные варианты
- Ссылайтесь на другие страницы сайта

❌ **Избегайте:**
- Слишком длинных ответов (более 300 слов)
- Технического жаргона
- Неактуальной информации
- Дублирования информации

### Примеры хороших вопросов

✅ "Во сколько заезд и выезд?"
✅ "Какие документы нужны при заселении?"
✅ "Можно ли отменить бронирование?"

❌ "Расскажите про заезд"
❌ "Что нужно знать о документах?"
❌ "Политика отмены"

## Техническая информация

### Модель данных

```python
class FAQ:
    question: str          # Вопрос (макс. 500 символов)
    answer: TextField      # Ответ (без ограничений)
    category: str          # Категория (choices)
    is_active: bool        # Опубликован на сайте
    sort_order: int        # Порядок сортировки
    created_at: datetime   # Дата создания
    updated_at: datetime   # Дата обновления
```

### URL-маршруты

- Публичная страница: `/faq/`
- Админ-панель: `/staff-admin/content/faq/`

### Шаблон

Расположение: `templates/content/faq.html`

## Поддержка

При возникновении проблем:
1. Проверьте права доступа пользователя
2. Убедитесь, что FAQ активен (галочка "Активен")
3. Очистите кэш браузера
4. Обратитесь к системному администратору
