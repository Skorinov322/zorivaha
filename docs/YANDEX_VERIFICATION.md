## 📊 Следующие шаги после верификации

### 1. Добавьте sitemap.xml

Создайте файл sitemap.xml со списком всех страниц сайта:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
    <url>
        <loc>https://ваш-домен.ru/</loc>
        <priority>1.0</priority>
    </url>
    <url>
        <loc>https://ваш-домен.ru/rooms/</loc>
        <priority>0.8</priority>
    </url>
    <url>
        <loc>https://ваш-домен.ru/faq/</loc>
        <priority>0.7</priority>
    </url>
    <!-- ... остальные страницы -->
</urlset>
```

Добавьте в Яндекс.Вебмастер:
1. Перейдите в **"Индексирование" → "Файлы Sitemap"**
2. Нажмите **"Добавить"**
3. Введите URL: `https://ваш-домен.ru/sitemap.xml`

### 2. Настройте robots.txt

Создайте файл robots.txt в корне сайта:

```
User-agent: *
Allow: /

Sitemap: https://ваш-домен.ru/sitemap.xml
```

### 3. Настройте региональность

1. Перейдите в **"Настройки" → "Региональность"**
2. Выберите регион: **Россия, Ханты-Мансийский АО**
3. Сохраните

### 4. Настройте главное зеркало

1. Перейдите в **"Настройки" → "Главное зеркало"**
2. Выберите предпочитаемый вариант:
   - `https://ваш-домен.ru` (рекомендуется)
   - `https://www.ваш-домен.ru`
3. Сохраните

### 5. Проверьте индексацию

1. Перейдите в **"Индексирование" → "Страницы в поиске"**
2. Проверьте, какие страницы проиндексированы
3. При необходимости отправьте страницы на переиндексацию

## 🛠️ Возможные проблемы

### Проблема: Файл не найден (404)

**Причина:** URL-маршрут не настроен или файл отсутствует

**Решение:**
1. Проверьте наличие файла: `templates/yandex_26cd3036c0f3861a.html`
2. Проверьте URL-маршрут в `config/urls.py`
3. Перезапустите сервер

### Проблема: Неверный формат файла

**Причина:** Файл поврежден или содержит неверный код

**Решение:**
1. Откройте файл `templates/yandex_26cd3036c0f3861a.html`
2. Убедитесь, что содержимое соответствует коду верификации
3. Сохраните файл в кодировке UTF-8

### Проблема: Яндекс не может получить доступ к файлу

**Причина:** Сайт недоступен или заблокирован

**Решение:**
1. Убедитесь, что сайт доступен из интернета
2. Проверьте настройки firewall
3. Проверьте настройки веб-сервера (Nginx/Apache)

## 📝 Примечания
