## ✂️ Что можно объединить/удалить

### 1. REVIEWS — объединить дубликаты
**Проблема:** 
- `hotel.RoomReview` (старая модель)
- `reviews.Review` (новая, более полная)

**Решение:**
```python

# Оставить: apps/reviews/models.py → Review (более функциональная)
```

**Миграция:**
1. Перенести данные из `hotel_roomreview` в `reviews_review`
2. Удалить модель `RoomReview`
3. Обновить связи в коде

### 3. ANALYTICS — радикально упростить

- `PageView` — избыточно (есть Google Analytics) ❌
- `BookingFunnel` — избыточно для малого отеля ❌

**Решение:**

### 4. CRM — упростить для малого отеля
**Проблема:**
- `Organization` — нужна для корпоративных клиентов ✅
- `ClientProfile` — нужна для лояльности ✅
- `AdminComment` — нужна ✅

**Решение:**

```python
- ClientProfile (лояльность, статистика)

```

## 🎯 Альтернатива: Мягкая оптимизация

Если не хотите радикальных изменений:

1. **Оставить все модели**, но:
   - Отключить ненужные в `INSTALLED_APPS`
   - Не использовать в коде
   - Удалить позже, когда будете уверены

2. **Пометить deprecated:**
```python
# apps/hotel/models.py
class RoomReview(models.Model):
    """
    DEPRECATED: Use apps.reviews.Review instead.
    This model will be removed in v2.0.
    """
    # ...
```

3. **Постепенная миграция:**
   - Новые отзывы → `reviews.Review`
   - Старые отзывы → оставить в `hotel.RoomReview`
   - Через 6 месяцев удалить старую модель
