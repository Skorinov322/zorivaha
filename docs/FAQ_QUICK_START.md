# Быстрый старт: Тестирование FAQ

## Подготовка окружения

### 1. Создайте .env файл (если его нет)

```bash
cp .env.example .env
```

### 2. Примените миграции

```bash
python manage.py migrate
```

### 3. Создайте суперпользователя (если нет)

```bash
python manage.py createsuperuser
```

## Наполнение FAQ примерами

### Автоматическое создание примеров

```bash
python manage.py create_sample_faq
```

Эта команда создаст 15 примеров FAQ по всем категориям.

## Запуск сервера

```bash
python manage.py runserver
```

## Проверка работы

### 1. Публичная страница FAQ

Откройте в браузере: http://127.0.0.1:8000/faq/

Вы должны увидеть:
- Красивый заголовок с градиентом
- FAQ, сгруппированные по категориям
- Аккордеоны с вопросами и ответами
- Блок "Не нашли ответ?" внизу страницы

### 2. Админ-панель

Откройте: http://127.0.0.1:8000/staff-admin/content/faq/

Здесь вы можете:
- Просматривать все FAQ
- Добавлять новые вопросы
- Редактировать существующие
- Активировать/деактивировать
- Изменять порядок сортировки
- Удалять FAQ

### 3. Навигация

Проверьте, что ссылка "FAQ" появилась:
- В главном меню (между "Галерея" и "Контакты")
- В футере сайта (раздел "Навигация")

## Тестирование функций

### Добавление нового FAQ

1. Войдите в админ-панель
2. Нажмите "Добавить FAQ"
3. Заполните:
   - Вопрос: "Тестовый вопрос?"
   - Ответ: "Тестовый ответ"
   - Категория: "Общее"
   - Активен: ✓
   - Порядок: 999
4. Сохраните
5. Откройте /faq/ и проверьте, что вопрос появился

### Деактивация FAQ

1. В списке FAQ снимите галочку "Активен"
2. Сохраните
3. Обновите /faq/ — вопрос должен исчезнуть

### Массовые операции

1. Выберите несколько FAQ (чекбоксы)
2. Выберите действие "Деактивировать выбранные FAQ"
3. Нажмите "Выполнить"
4. Проверьте результат на /faq/

## Возможные проблемы

### FAQ не отображаются

**Причина:** FAQ деактивированы
**Решение:** В админке проверьте галочку "Активен"

### Ошибка 404 на /faq/

**Причина:** URL не подключен
**Решение:** Проверьте config/urls.py — должна быть строка:
```python
path("", include("apps.content.urls", namespace="content")),
```

### Нет ссылки в меню

**Причина:** Шаблон не обновлен
**Решение:** Проверьте templates/partials/_navbar.html
