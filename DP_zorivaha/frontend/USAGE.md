# 📖 Руководство по использованию статической копии

## 🎯 Назначение

Эта папка содержит **статическую копию клиентской части** проекта "Зори Ваха" - только HTML, CSS и JavaScript, без Django backend.

## 🚀 Быстрый старт

### Вариант 1: Открыть напрямую
```bash
# Просто откройте файл в браузере
open frontend/index.html  # macOS
start frontend/index.html # Windows
xdg-open frontend/index.html # Linux
```

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# Python 3
cd frontend
python -m http.server 8000

# Затем откройте http://localhost:8000
```

### Вариант 3: Live Server (VS Code)
1. Установите расширение "Live Server"
2. Правый клик на `index.html` → "Open with Live Server"

## 🎨 Дизайн и стилизация

### Цветовая схема
```css
--background:    #eff0f3  /* Основной фон */
--headline:      #0d0d0d  /* Заголовки */
--paragraph:     #2a2a2a  /* Текст */
--button:        #ff8e3c  /* Кнопки (оранжевый) */
--secondary:     #ffffff  /* Карточки */
--tertiary:      #d9376e  /* Акцент (розовый) */
```

### Типографика
- **Заголовки**: `Cormorant Garamond` (serif) - элегантный шрифт для заголовков
- **Текст**: `DM Sans` (sans-serif) - современный читаемый шрифт

### Ключевые компоненты

#### Кнопки
```html
<a href="#" class="btn-luxury">Основная кнопка</a>
<a href="#" class="btn-luxury-outline">Вторичная кнопка</a>
<a href="#" class="btn-gold-sm">Маленькая кнопка</a>
```

#### Карточки
```html
<div class="luxury-card">
  <!-- Контент карточки -->
</div>
```

#### Анимации
```html
<div class="reveal">
  <!-- Элемент появится при скролле -->
</div>
```

## 📱 Адаптивность

Все страницы адаптированы для:
- **Desktop**: 1400px и выше
- **Tablet**: 768px - 1399px
- **Mobile**: до 768px

Брейкпоинты:
```css
@media (max-width: 900px) { /* Планшеты */ }
@media (max-width: 768px) { /* Мобильные */ }
@media (max-width: 600px) { /* Маленькие мобильные */ }
@media (max-width: 480px) { /* Очень маленькие */ }
```

## 🔧 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в `css/main.css`:
```css
:root {
  --button: #your-color;  /* Основной цвет */
  --background: #your-bg; /* Фон */
}
```

### Добавление страниц
1. Создайте новый HTML файл в `pages/`
2. Скопируйте структуру из существующей страницы
3. Обновите навигацию в header

### Изменение контента
Просто отредактируйте HTML файлы - все данные статичны.

## 🔄 Обновление статической копии

Если вы изменили Django шаблоны и хотите обновить статическую копию:

```bash
# Запустите скрипт генерации
python frontend/generate_static.py
```

Скрипт автоматически:
- Читает Django шаблоны
- Удаляет Django теги
- Заменяет URL на относительные пути
- Генерирует чистый HTML

## 📦 Деплой

### GitHub Pages
```bash
# Скопируйте содержимое frontend/ в корень gh-pages ветки
git checkout -b gh-pages
cp -r frontend/* .
git add .
git commit -m "Deploy static site"
git push origin gh-pages
```

### Netlify / Vercel
1. Загрузите папку `frontend/`
2. Укажите `index.html` как точку входа
3. Готово!

### Обычный хостинг
1. Загрузите все файлы из `frontend/` на сервер
2. Убедитесь что `index.html` в корне
3. Настройте веб-сервер (Apache/Nginx)

## 🐛 Известные проблемы

1. **Формы не работают** - нет backend для обработки
   - Решение: Используйте сервисы типа Formspree или EmailJS

2. **Нет динамических данных** - все статично
   - Решение: Используйте основной Django проект

3. **Некоторые ссылки ведут на #** - заглушки для функций требующих backend
   - Решение: Нормально для статической копии

## 💡 Советы

1. **Для разработки** используйте локальный сервер, не открывайте файлы напрямую

3. **Для SEO** добавьте meta-теги и sitemap.xml
