# FAQ система для гостиницы "Зори Ваха"

## 🎯 Описание

Полнофункциональная система управления часто задаваемыми вопросами (FAQ) с админ-панелью и публичной страницей.

## ✨ Возможности

### Для администраторов
- ✅ Управление FAQ через удобную админ-панель
- ✅ 5 категорий вопросов (Бронирование, Заезд/Выезд, Услуги, Оплата, Общее)
- ✅ Массовые операции (активация, деактивация, удаление)
- ✅ Гибкая сортировка вопросов
- ✅ Права доступа по ролям

### Для гостей
- ✅ Красивая публичная страница с FAQ
- ✅ Группировка по категориям с иконками
- ✅ Удобные аккордеоны для вопросов/ответов
- ✅ Адаптивный дизайн (мобильные, планшеты, desktop)
- ✅ Быстрая загрузка и плавные анимации

## 🚀 Быстрый старт


## 🔧 Управление FAQ

### Добавление нового вопроса

1. Войдите в админ-панель: `/staff-admin/`
2. Перейдите в **Content → FAQ**
3. Нажмите **"Добавить FAQ"**
4. Заполните поля:
   - Вопрос
   - Ответ
   - Категория
   - Активен ✓
   - Порядок сортировки
5. Сохраните

### Редактирование

1. В списке FAQ нажмите на вопрос
2. Внесите изменения
3. Сохраните

### Деактивация

Чтобы временно скрыть вопрос:
- Снимите галочку **"Активен"**
- Или используйте массовое действие **"Деактивировать"**

## 💡 Примеры использования

### Создание FAQ программно

```python
from apps.content.models import FAQ

faq = FAQ.objects.create(
    question="Во сколько заезд?",
    answer="Заезд с 14:00, выезд до 12:00",
    category=FAQ.FAQCategory.CHECKIN,
    is_active=True,
    sort_order=1
)
```

### Получение активных FAQ

```python
faqs = FAQ.objects.filter(is_active=True).order_by("category", "sort_order")
```

### Группировка по категориям

```python
from collections import defaultdict

faqs_by_category = defaultdict(list)
for faq in FAQ.objects.filter(is_active=True):
    faqs_by_category[faq.get_category_display()].append(faq)
```
