# Деплой на Render.com

## Шаг 1: Подготовка

1. Зарегистрируйтесь на https://render.com (можно через GitHub)
2. Убедитесь, что ваш код залит на GitHub

## Шаг 2: Создание проекта

1. Откройте https://dashboard.render.com/
2. Нажмите **"New +"** → **"Blueprint"**
3. Подключите ваш GitHub репозиторий **Skorinov322/zorivaha**
4. Render автоматически найдёт файл `render.yaml` и создаст:
   - Web Service (приложение Django)
   - PostgreSQL Database (база данных)

## Шаг 3: Настройка переменных окружения

После создания проекта, откройте настройки Web Service и добавьте:

### Обязательные переменные:

```
ALLOWED_HOSTS = ваш-домен.onrender.com
CSRF_TRUSTED_ORIGINS = https://ваш-домен.onrender.com
```

**Важно:** Замените `ваш-домен` на реальный домен, который Render выдаст вам (например, `zorivaha.onrender.com`)

### Переменные, которые Render создаст автоматически:
- `DATABASE_URL` - подключение к PostgreSQL
- `SECRET_KEY` - секретный ключ Django
- `DJANGO_SETTINGS_MODULE` - уже установлен в `config.settings.prod`
- `DEBUG` - уже установлен в `False`

## Шаг 4: Деплой

1. Render автоматически начнёт деплой после создания проекта
2. Процесс займёт 5-10 минут
3. Следите за логами в разделе "Logs"

## Шаг 5: Создание суперпользователя

После успешного деплоя:

1. Откройте **Shell** в настройках Web Service
2. Выполните команду:
```bash
python manage.py createsuperuser
```
3. Введите email, имя пользователя и пароль

## Шаг 6: Проверка

Откройте ваш сайт: `https://ваш-домен.onrender.com`

## Важные замечания

- **Free план**: первый запрос может занять 30-60 секунд (сервис "засыпает" после 15 минут неактивности)
- **База данных**: PostgreSQL на free плане имеет ограничение 90 дней, после чего нужно будет пересоздать
- **Логи**: доступны в реальном времени в разделе "Logs"

## Обновление кода

При каждом push в GitHub ветку `main`, Render автоматически:
1. Скачает новый код
2. Запустит `build.sh` (установка зависимостей, миграции, статика)
3. Перезапустит приложение

## Troubleshooting

Если что-то не работает:
1. Проверьте логи в разделе "Logs"
2. Убедитесь, что все переменные окружения установлены правильно
3. Проверьте, что база данных создана и подключена
