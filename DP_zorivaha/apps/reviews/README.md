# Система отзывов

## Описание

Полнофункциональная система отзывов гостей с модерацией для отеля "Зори Ваха".

## Основные возможности

### Для гостей:
- ✅ Оставить отзыв на завершенное бронирование (checked_out)
- ✅ Оценить проживание по 6 критериям (1-5 звезд):
  - Общая оценка
  - Чистота
  - Комфорт
  - Персонал
  - Соотношение цена/качество
  - Расположение
- ✅ Написать текстовый отзыв с достоинствами и недостатками
- ✅ Просмотреть свои отзывы в личном кабинете
- ✅ Увидеть ответ администрации на свой отзыв

### Для персонала (ресепшн и выше):
- ✅ Модерация отзывов (одобрение/отклонение)
- ✅ Просмотр всех отзывов с фильтрацией по статусу
- ✅ Счетчики отзывов на модерации
- ✅ История модерации (аудит-лог)

### Для менеджеров и администраторов:
- ✅ Все возможности ресепшена
- ✅ Ответ на отзывы от имени администрации
- ✅ Отметка избранных отзывов для главной страницы
- ✅ Полный доступ через админ-панель Django

### Публичные страницы:
- ✅ Список всех опубликованных отзывов
- ✅ Детальная страница отзыва с ответом администрации
- ✅ Статистика (средняя оценка, количество отзывов)
- ✅ Избранные отзывы
- ✅ Сортировка (новые, лучшие, худшие)

## Модели

### Review
Основная модель отзыва:
- Связь с бронированием (OneToOne)
- Связь с автором (User)
- 6 оценок по разным критериям (1-5)
- Текстовые поля (заголовок, текст, плюсы, минусы)
- Статус модерации (pending/approved/rejected)
- Метаданные (IP, User-Agent)

### ReviewResponse
Ответ администрации на отзыв:
- Связь с отзывом (OneToOne)
- Автор ответа (сотрудник)
- Текст ответа
- Должность автора

### ReviewModeration
История модерации (аудит-лог):
- Иммутабельная запись
- Действие (approved/rejected/edited/deleted)
- Модератор
- Комментарий
- Снимок данных (JSON)

## URL-маршруты

### Публичные:
- `/reviews/` — список отзывов
- `/reviews/<uuid>/` — детальная страница отзыва

### Для гостей:
- `/reviews/create/<booking_id>/` — создать отзыв
- `/reviews/my/` — мои отзывы

### Для персонала:
- `/reviews/moderation/` — список отзывов для модерации
- `/reviews/moderation/<uuid>/` — модерировать отзыв
- `/reviews/respond/<uuid>/` — ответить на отзыв

## Бизнес-логика

### Правила создания отзыва:
1. Бронирование должно быть завершено (status = checked_out)
2. Пользователь должен быть гостем этого бронирования
3. На одно бронирование можно оставить только один отзыв
4. Все оценки обязательны (1-5)

### Модерация:
1. Новый отзыв создается со статусом "pending"
2. Ресепшн/менеджер/админ может одобрить или отклонить
3. При одобрении отзыв публикуется автоматически
4. При отклонении указывается причина
5. История модерации сохраняется в аудит-логе

### Ответы администрации:
1. Отвечать можно только на одобренные отзывы
2. На один отзыв — один ответ
3. Ответ публикуется сразу без модерации
4. Автор и должность сохраняются для отображения

## Интеграция

### В личном кабинете гостя:
- Кнопка "Оставить отзыв" на странице завершенного бронирования
- Раздел "Мои отзывы" с отображением статуса модерации

### В админ-панели:
- Полное управление отзывами
- Массовые действия (одобрить/отклонить)
- Inline для ответов администрации
- История модерации

### На публичном сайте:
- Страница со всеми отзывами
- Виджет избранных отзывов (можно встроить на главную)
- Статистика и средние оценки

## Использование

### Создание отзыва:
```python
from apps.reviews.models import Review

review = Review.objects.create(
    booking=booking,
    author=user,
    overall_rating=5,
    cleanliness_rating=5,
    comfort_rating=4,
    staff_rating=5,
    value_rating=4,
    location_rating=5,
    title="Отличный отель!",
    text="Все понравилось...",
    pros="Чистота, персонал",
    cons="Немного шумно",
)
```

### Модерация:
```python
# Одобрить
review.approve(moderator=request.user, comment="Отзыв проверен")

# Отклонить
review.reject(moderator=request.user, reason="Нецензурная лексика")
```

### Ответ администрации:
```python
from apps.reviews.models import ReviewResponse

response = ReviewResponse.objects.create(
    review=review,
    author=admin_user,
    text="Спасибо за отзыв!",
    author_position="Администратор",
)
```

### Получение данных:
```python
from apps.reviews.selectors import (
    get_published_reviews,
    get_featured_reviews,
    get_review_statistics,
)

# Опубликованные отзывы
reviews = get_published_reviews()

# Избранные для главной
featured = get_featured_reviews(limit=3)

# Статистика
stats = get_review_statistics()
# {
#     'total_count': 42,
#     'average_overall': 4.5,
#     'average_cleanliness': 4.7,
#     ...
#     'rating_distribution': {1: 0, 2: 1, 3: 5, 4: 15, 5: 21}
# }
```
