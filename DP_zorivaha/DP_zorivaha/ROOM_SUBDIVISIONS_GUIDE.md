# Руководство по подразделениям номеров и множественному заселению

## Обзор функциональности

Система теперь поддерживает:
1. **Подразделения номеров** - разделение одного номера на части (например, 303а, 303б)
2. **Множественное заселение** - возможность заселения нескольких гостей в один номер одновременно

## Новые возможности

### Подразделения номеров
- Номера могут иметь подразделения (а, б, в и т.д.)
- Каждое подразделение является отдельным номером для бронирования
- Пример: номер 303 может быть разделен на 303а и 303б

### Множественное заселение
- Номера могут принимать несколько броней одновременно
- Особенно полезно для номеров эконом-класса
- Администратор видит текущую заполненность (например, 2/3)

## Настройка номеров

### Автоматическая настройка
Выполните команду для создания примеров номеров эконом-класса:
```bash
python manage.py setup_economy_rooms
```

Для предварительного просмотра без создания:
```bash
python manage.py setup_economy_rooms --dry-run
```

### Ручная настройка
В админ-панели при создании/редактировании номера:
1. **Номер комнаты** - основной номер (например, 303)
2. **Подразделение** - буквенное обозначение (а, б, в) - необязательно
3. **Макс. одновременных броней** - количество гостей, которые могут одновременно находиться в номере

## Использование

### Для администраторов
1. При заселении гостя можно выбрать конкретный номер из списка доступных
2. В списке номеров показывается текущая заполненность для номеров с множественным заселением
3. Номера с подразделениями отображаются как "303а", "303б" и т.д.

### Логика доступности
- Номер доступен для бронирования, если текущее количество броней меньше максимального
- При заселении/выселении статус номера обновляется автоматически
- Номер помечается как "Занят" только когда достигнута максимальная заполненность

## Примеры использования

### Номер с подразделениями
- Номер 303а (макс. 2 брони) - может принять 2 отдельные брони
- Номер 303б (макс. 2 брони) - может принять 2 отдельные брони

### Номер с множественным заселением
- Номер 305 (макс. 3 брони) - может принять 3 отдельные брони одновременно
- Показывается как "305 (1/3)" когда заселен 1 гость из 3 возможных

## Миграция данных

Существующие номера автоматически получают:
- Пустое подразделение
- Максимум 1 одновременная бронь (текущее поведение)

Новые номера можно настроить с любыми параметрами.

## Технические детали

### Изменения в моделях
- `Room.subdivision` - новое поле для подразделения
- `Room.max_concurrent_bookings` - максимальное количество одновременных броней
- `Room.full_number` - свойство, возвращающее полный номер с подразделением

### Изменения в логике
- Обновлена логика проверки доступности номеров
- Изменена логика обновления статуса номера при заселении/выселении
- Добавлена поддержка выбора конкретного номера при заселении

### Административный интерфейс
- Обновлен список номеров с отображением заполненности
- Добавлены поля для настройки подразделений и множественного заселения
- Улучшено отображение номеров в формах бронирования
