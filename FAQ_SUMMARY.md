## 🚀 Как использовать

### Шаг 1: Создать примеры
```bash
python manage.py create_sample_faq
```

### Шаг 2: Запустить сервер
```bash
python manage.py runserver
```

### Шаг 3: Открыть страницы
- Публичная: http://127.0.0.1:8000/faq/
- Админка: http://127.0.0.1:8000/staff-admin/content/faq/
