# Реализация FAQ на сайте

## ✅ Что реализовано

### 1. **Модель данных** (`apps/content/models.py`)
- Модель `FAQ` с полями:
  - `question` — вопрос (до 500 символов)
  - `answer` — ответ (текстовое поле)
  - `category` — категория (5 вариантов)
  - `is_active` — флаг публикации
  - `sort_order` — порядок сортировки
  - Автоматические поля: `created_at`, `updated_at`

### 2. **Админ-панель** (`apps/content/admin.py`)
- Полное управление FAQ через Django Admin
- Права доступа по ролям:
  - Просмотр: Manager+
  - Редактирование: Manager+
  - Удаление: Admin+
- Массовые операции:
  - Активация/деактивация
  - Удаление
- Фильтры по категориям и статусу
- Поиск по вопросам и ответам
- Редактирование порядка прямо в списке

### 3. **Публичная страница** (`templates/content/faq.html`)
- Красивый дизайн с градиентным заголовком
- Группировка по категориям с иконками
- Аккордеоны для вопросов/ответов
- Адаптивная верстка (мобильные устройства)
- Блок призыва к действию внизу страницы
- Плавные анимации

### 4. **View** (`apps/content/views.py`)
- `FAQListView` — отображение активных FAQ
- Автоматическая группировка по категориям
- Сортировка по `sort_order`

### 5. **URL-маршруты**
- `/faq/` — публичная страница
- `/staff-admin/content/faq/` — админ-панель

### 6. **Интеграция в навигацию**
- Ссылка в главном меню (между "Галерея" и "Контакты")
- Ссылка в футере сайта
- Адаптивное мобильное меню

### 7. **Management команда**
- `python manage.py create_sample_faq` — создание 15 примеров FAQ
- Покрывает все 5 категорий
- Реалистичный контент для гостиницы

### 8. **Документация**
- `docs/FAQ_GUIDE.md` — полное руководство для администраторов
- `docs/FAQ_QUICK_START.md` — быстрый старт для тестирования
- Этот файл — обзор реализации

## 🔧 Технические детали

### Модель FAQ

```python
class FAQ(TimeStampedModel, OrderedModel):
    question = CharField(max_length=500)
    answer = TextField()
    category = CharField(choices=FAQCategory.choices)
    is_active = BooleanField(default=True)
    sort_order = IntegerField()
```

### Категории

```python
class FAQCategory(TextChoices):
    BOOKING = "booking", "Бронирование"
    CHECKIN = "checkin", "Заезд и выезд"
    SERVICES = "services", "Услуги"
    PAYMENT = "payment", "Оплата"
    GENERAL = "general", "Общее"
```

### View

```python
class FAQListView(ListView):
    model = FAQ
    template_name = "content/faq.html"
    
    def get_queryset(self):
        return FAQ.objects.filter(is_active=True).order_by("category", "sort_order")
```

## 🚀 Как использовать

### Для администраторов

1. **Войдите в админ-панель**: `/staff-admin/`
2. **Перейдите в FAQ**: Content → FAQ
3. **Добавьте вопрос**: кнопка "Добавить FAQ"
4. **Заполните поля**:
   - Вопрос
   - Ответ (поддерживает переносы строк)
   - Категория
   - Активен ✓
   - Порядок сортировки
5. **Сохраните**

### Для разработчиков

```bash
# Создать примеры FAQ
python manage.py create_sample_faq

# Проверить страницу
http://127.0.0.1:8000/faq/

# Админ-панель
http://127.0.0.1:8000/staff-admin/content/faq/
```

## 📊 Примеры FAQ

Команда `create_sample_faq` создает 15 вопросов:

**Бронирование** (3 вопроса)
- Как забронировать номер?
- Можно ли отменить или изменить бронирование?
- Нужна ли предоплата при бронировании?

**Заезд и выезд** (3 вопроса)
- Во сколько заезд и выезд?
- Какие документы нужны при заселении?
- Можно ли заселиться раньше или выехать позже?

**Услуги** (3 вопроса)
- Какие удобства есть в номерах?
- Есть ли парковка?
- Можно ли разместиться с домашними животными?

**Оплата** (3 вопроса)
- Какие способы оплаты вы принимаете?
- Предоставляете ли вы отчетные документы?
- Возможен ли возврат средств при отмене?

**Общее** (3 вопроса)
- Где вы находитесь?
- Есть ли у вас ресторан или кафе?
- Как связаться с администрацией?
