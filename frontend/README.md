# 🎨 Frontend — Статическая копия Зори Ваха

Это статическая копия клиентской части проекта "Зори Ваха", содержащая только HTML, CSS и JavaScript файлы.

## 📁 Структура

```
frontend/
├── index.html              # Главная страница
├── pages/                  # Остальные страницы
│   ├── rooms.html         # Каталог номеров
│   ├── room-detail.html   # Детальная страница номера
│   ├── about.html         # О гостинице
│   ├── contacts.html      # Контакты
│   └── gallery.html       # Галерея
├── css/                    # Стили
│   ├── main.css           # Основные стили
│   ├── hotel.css          # Стили для публичных страниц
│   ├── grand-soleil.css   # Дизайн-система
│   └── admin_custom.css   # Стили админки
├── js/                     # JavaScript
│   ├── main.js            # Основной JS
│   └── booking.js         # JS для бронирования
└── img/                    # Изображения
    └── logoZV.png         # Логотип

```

## 🚀 Использование

1. Откройте `index.html` в браузере
2. Навигация работает через относительные ссылки
3. Все стили и скрипты подключены локально

## 🎨 Дизайн-система

### Цветовая палитра
- **Primary (Orange)**: `#ff8e3c` - основной акцентный цвет
- **Background**: `#eff0f3` - основной фон
- **Headline**: `#0d0d0d` - заголовки
- **Paragraph**: `#2a2a2a` - основной текст
- **Secondary**: `#ffffff` - вторичный фон (карточки)
- **Tertiary**: `#d9376e` - дополнительный акцент

### Типографика
- **Заголовки**: Cormorant Garamond (serif)
- **Основной текст**: DM Sans (sans-serif)

### Компоненты
- Кнопки: `.btn-luxury`, `.btn-luxury-outline`, `.btn-gold-sm`
- Карточки: `.luxury-card`, `.room-card`
- Разделители: `.gold-divider`
- Анимации: `.reveal`, `.anim-fade-up`

## 📱 Адаптивность

Все страницы адаптированы для:
- Desktop (1400px+)
- Tablet (768px - 1399px)
- Mobile (< 768px)

## ⚡ Особенности

- **Server-Side Rendering (SSR)** - страницы рендерятся на сервере
- **Progressive Enhancement** - базовая функциональность работает без JS
- **Intersection Observer** - анимации появления элементов
- **Responsive Images** - оптимизация изображений
- **Accessibility** - семантическая разметка и ARIA-атрибуты

## 🔗 Навигация

- `/index.html` - Главная
- `/pages/rooms.html` - Каталог номеров
- `/pages/room-detail.html` - Детальная страница номера
- `/pages/about.html` - О гостинице
- `/pages/contacts.html` - Контакты
- `/pages/gallery.html` - Галерея

## 📝 Примечания

Это статическая копия, поэтому:
- Формы не отправляют данные (нет backend)
- Динамические данные заменены на примеры
- Ссылки на Django URL заменены на относительные пути
- Нет аутентификации и личного кабинета

Для полной функциональности используйте основной Django проект.
